# Coverage Certification Under Population-Mixture Shift from Imperfect Group Proxies

Research software and manuscript source for a JMLR-targeted working paper.

**Status:** Reproducible research draft; not yet accepted or published. Please see `README_RESEARCH.md` for methods, reproduction instructions, and limitations.

The associated experiments analyze prediction-set coverage under latent group-mixture shift and imperfect proxy group indicators. The repository contains LaTeX, Python experiments, numerical results, figures and tests.
